# Política de segurança

## Versões suportadas

| Versão | Suporte |
| --- | --- |
| 0.1.x | Sim |
| Anteriores a 0.1.0 | Não |

## Reportar uma vulnerabilidade

Não abra uma issue pública para problemas de segurança. Use o formulário privado [Report a vulnerability](https://github.com/Daniellpego/Sussurro/security/advisories/new).

Inclua a versão afetada, a versão do Windows, os passos para reproduzir e o impacto esperado. Uma demonstração mínima ajuda, mas não envie transcrições reais, arquivos de `%APPDATA%\Sussurro` ou outros dados pessoais.

O mantenedor responderá pelo próprio advisory e coordenará a correção antes de uma divulgação pública. O prazo depende da gravidade e da complexidade do problema.
