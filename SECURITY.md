# Política de Segurança

## Dados sensíveis

O Sussurro processa áudio e mantém histórico local. Arquivos de `%APPDATA%\Sussurro`, gravações, logs e configurações pessoais não devem ser anexados publicamente sem revisão/anonimização.

## Relatando uma vulnerabilidade

Para uma vulnerabilidade que possa expor dados, executar código, contornar isolamento ou comprometer a máquina do usuário, prefira um **GitHub Security Advisory privado** do repositório em vez de uma issue pública.

Issues públicas são adequadas para bugs sem impacto de segurança e sem dados sensíveis.

Ao relatar, inclua versão/commit, Windows utilizado, passos mínimos para reproduzir e impacto observado. Não inclua tokens, arquivos pessoais ou conteúdo de transcrições reais que não sejam necessários.
