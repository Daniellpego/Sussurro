# Referências de design

Esta pasta mantém as especificações textuais e os protótipos HTML usados como referência visual do Sussurro.

Arquivos PNG renderizados e o bundle de handoff (`support.js` e o export de canvas) não fazem parte do runtime. Como podem ser reproduzidos a partir das fontes, não são versionados.

Alguns documentos registram decisões históricas de design e podem mencionar ideias que não chegaram ao produto. A arquitetura vigente está em [`../ARCHITECTURE.md`](../ARCHITECTURE.md).
