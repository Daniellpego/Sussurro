Modos de Transcrição

Configure os prompts do LLM para processar suas gravações.

RAW

Transcrição exata sem processamento LLM. Mantém pausas e hesitações.

CLEAN
Ativo

Remove hesitações ("humm", "ééé"), corrige gramática básica e organiza em parágrafos coesos mantendo o tom original.

EMAIL

Converte a fala em um rascunho de e-mail profissional, identificando destinatário, assunto e ação desejada se mencionados.

BULLETS

Resume a transcrição em uma lista concisa de pontos-chave (bullet points). Ideal para notas rápidas.

PROMPT

Otimiza a fala para ser usada como um prompt para outros modelos de IA (ex: Midjourney, ChatGPT).

CODE

Formata pseudo-código ou descrições técnicas faladas em blocos de código formatados na linguagem inferida.

TRANSLATE

Tradução direta da fala (Português -> Inglês) mantendo o contexto limpo.
